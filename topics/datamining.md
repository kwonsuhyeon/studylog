## 한 줄 정의

대량의 데이터에서 유용한 패턴을 찾는 방법. 객체 사이의 거리·유사도, 함께 나타나는 항목을 찾는 연관규칙, 레코드를 클래스로 나누는 분류, 비슷한 레코드를 묶는 군집으로 나뉜다. 고성능데이터마이닝 수업(2026-2)과 Tan 외 *Introduction to Data Mining* 2판(2·3·5·7장)을 기준으로 정리한다.

## 지금까지 정리한 것

- **거리·유사도**: 민코프스키 거리(맨해튼 L1, 유클리드 L2, 상한 L∞), 이진 벡터의 SMC와 Jaccard, 코사인 유사도, 상관계수, 표준화
- **연관규칙 평가**: 지지도 s(X→Y) = σ(X∪Y)/N, 신뢰도 c = σ(X∪Y)/σ(X), 향상도 = c/P(Y)(1보다 작으면 음의 연관)
- **Apriori**: 빈발 항목집합의 부분집합도 빈발(지지도의 반단조성)하다는 원리로 후보를 가지치기. 표 5.1 예에서 후보 41개 → 13개
- **FP-Growth**: FP-tree로 거래를 압축하고 후보 생성 없이 조건부 패턴 베이스를 재귀로 마이닝
- **결정트리**: 지니·엔트로피·분류 오차, 정보 이득과 이득비, 연속 속성 분할점
- **가지치기**: 비관적 오차 추정 e'(T) = (e(T) + Ω·k)/N, 사전 가지치기(노드의 레코드 수 임계값 등)와 사후 가지치기(subtree replacement·raising)
- **K-means**: 초기 중심 → 가장 가까운 중심에 배정 → 평균으로 중심 갱신 반복, SSE, 초기화 문제와 K-means++
- **kNN**: 게으른 학습, 거리·k·다수결, 거리 가중 투표, 정규화가 필요한 이유
